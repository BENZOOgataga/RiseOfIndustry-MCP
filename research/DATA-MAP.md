## How to read this map

- **Asm / NS**: `AC / PA` means `Assembly-CSharp.dll`, namespace `ProjectAutomata` (the default). Other values are spelled out. `-` means a derived value.
- **Access**: the recommended read path (member paths and plain-language steps). It always runs on the Unity main thread.
- **Source**: where the value lives. `STATIC` = Game definition data (GameData assets, content mods). Constant for a game module.; `SAVE` = Persisted in the .sav file and restored on load.; `RUNTIME` = Only in live memory (recomputed or transient).; `DERIVED` = Computed deterministically by the observer or MCP server from other values.
- **Safety**: `SAFE` = Pure field/property read with no side effects. Main thread only (applies to everything).; `SAFE_REFLECTION` = Pure read of a private/protected field via FieldInfo.GetValue. Main thread only. Version-coupled.; `CAUTION` = Side-effect free but costly, allocating, pooled (ListPool) or returning a live collection that must be copied immediately.; `AVOID_USE_ALTERNATIVE` = The obvious getter/method has a side effect (dictionary insert, RNG, cache mutation, GUID minting). Use the access path given instead.; `DERIVED` = Not read from the game; computed from other entries.; `NOT_AVAILABLE` = The game does not hold this data.
- **Conf.**: `CONFIRMED` = Read directly in decompiled source, game files, or save bytes.; `HIGH` = Strongly implied; one link not directly observed (usually prefab/asset data).; `INFERRED` = Reasoned from naming/usage; not verified.; `UNKNOWN` = Not determined.
- **Avoid**: members that look like reads but must not be called, and why.
- **Evidence**: file:line in `research/_local/decompiled/Assembly-CSharp/ProjectAutomata/` unless prefixed; `notes/...` refers to `research/notes/`.

## Global rules for every read

- Every read happens on the Unity main thread (game collections are unsynchronized; ManagerBehaviour<T>.instance, ListPool, Formula pools and GetComponent are main-thread-only).
- Use Unity null checks (the overloaded bool conversion or comparison with null on UnityEngine.Object) on managers and game objects; destroyed objects remain referenced.
- Never call setters, Set*/Add*/Remove*/Clear*/Toggle*/Increment*/Decrement*, Validate*, Unlock*, Research*, Purchase*/Sell*, or any view-model method.
- Never call Utils.GetSafe-backed getters on game dictionaries; read the dictionary with TryGetValue.
- Never call GuidMapper.GetGUIDForObject, MoneyManager.GetBalance/GetRawBalance/RegisterAgent, DevConsole.Console.ExecuteCommand, SavegameManager.CreateSavegame, GameData.editorInstance.
- Copy live collections (List/HashSet/Queue/ReadOnlyList) into observer-owned buffers before yielding a frame.
- Use Player.humanPlayer for 'the player', never Player.activeActor (UI/debug can switch it) and never call Player.SetActiveActor.
